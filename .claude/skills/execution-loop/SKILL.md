# execution-loop — 하네스 실행 루프

이 저장소에서 코드/기능 작업을 할 때 아래 사이클을 따른다.
근거: [CLAUDE.md](../../../CLAUDE.md), [docs/verification-rubric.md](../../../docs/verification-rubric.md).

## 7단계 사이클
1. **계획** — 영향 파일·위험 요소 파악. plan.md/architecture.md 참조.
2. **완료조건 합의** — 이 작업의 DoD를 명시(어떤 루브릭 항목을 만족해야 하나).
3. **교육 설계 검토** — 변경이 설계원리.md 6원리에 부합하는지 확인.
4. **구현** — 최소 변경 + 단위/접근성 테스트 포함.
5. **교육학 검토** — 정답 즉답 금지 등 절대 규칙 위반 없는지 확인.
6. **검증** — 루브릭 6차원 측정. D1·D2는 만점 필수.
7. **하네스 진화** — 허점 발견 시 HARNESS_CHANGELOG.md에 규칙 누적(사람 승인).

## 종료 조건
- 모든 차원 ≥2, D1·D2 =3 → 완료로 표시하고 docs/progress.md 갱신.
- 미달 → 4번으로 복귀.

## 불변 규칙
- 루브릭을 스스로 완화하지 않는다.
- 시크릿을 커밋/클라이언트에 넣지 않는다.
