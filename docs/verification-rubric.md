# docs/verification-rubric.md — 6차원 검증 루브릭

> "완료"는 이 기준 통과를 의미한다. **루브릭 변경은 사람 승인 필수**([HARNESS_CHANGELOG.md](../HARNESS_CHANGELOG.md)).
> 각 차원 0~3점. 통과 기준: 모든 차원 ≥2, 1·2번(교육학) 차원은 ≥3 필수.

## D1. 교육학 충실도 (필수 만점)
- [ ] 자기설명 제출 전 정답/해석을 제시하지 않는다 (원리4.1)
- [ ] 오답/오연결에 정답 대신 재탐색 단서를 준다 (2.5, 6.4)
- [ ] 6개 설계원리가 단계에 매핑되어 동작한다
- 측정: 정답 유출 테스트 케이스 통과율 100%

## D2. 진단 정확도 (필수 만점)
- [ ] 막힌 과정(선별/통합/구조/추론)을 올바르게 구분
- [ ] 표시 개수가 아닌 '무엇을 선택했는지'로 진단 (원리5)
- 측정: 라벨링된 진단 케이스셋 대비 정확도 ≥ 목표치

## D3. 비계 적절성
- [ ] 학습자 수준·이력에 따라 단서 구체성 조절 (원리6)
- [ ] 잘하는 학습자에게 일률적 밑줄/정답 제공 안 함 (6.3)

## D4. 기능 정확성
- [ ] 주석 저장/렌더(밑줄·동그라미·화살표) 단위테스트 통과
- [ ] 세션 단계 전이 통합테스트 통과
- [ ] 빌드/타입체크/린트 통과

## D5. 접근성·UX
- [ ] 키보드 조작 가능, 스크린리더 라벨 제공
- [ ] 모바일 뷰포트 정상 렌더
- [ ] 로딩/에러 상태 처리

## D6. 보안·비용
- [ ] 클라이언트 번들에 시크릿 없음(CI 스캔)
- [ ] RLS 정책 유효(학생/교사 접근 테스트)
- [ ] `model_used`·토큰·비용 로깅, 승급 상한 존재
- [ ] 학생 식별정보 URL/로그 미포함

## 자동화
- pre-commit: 린트·타입체크·시크릿 스캔
- CI: 빌드·테스트·D1 정답유출 케이스
- 수동: D2/D3 케이스 리뷰(교육학), 승인 시 진행
